PROJECT 01活跃

CoTape

CoTape（拼矿矿）是 BNB Chain 上的芯片设计与材料合作平台：设计者发布经完整验证的网表，出资者按 NAND 份额拼单提供制造材料；出资到位、设计者缴足押金后流片，矿机由合约托管开挖。基础挖矿收益归出资者，最优加成扣除平台费后按挂单约定分配。

PROJECT 02活跃

EmberWorld

EmberWorld（余烬世界）是 X Layer 上以电路队友为特色的 DeWEB 动作冒险游戏，计划复用 TapeOut 生态矿机网表构建队友的战术大脑，优先以 FabX 网表接入为开发方向。其玩法规划保留免费手动游玩入口，通过 EmberWorld Pass NFT 解锁电路协作，并支持 NFT 装备交易。官网展示了前作《余烬》的电路战斗演示；完整《余烬世界》、矿机接入与道具商店仍在开发中。

PROJECT 03活跃

Fab X

Fab X 是 X Layer 上的 TapeOut 社区矿机平台。用户使用 NAND 与 LATCH 设计电路，流片为电路 NFT，再认领题目并通过验证，参与 FAB 挖矿。官网提供支持 AI 辅助设计的电路画布、晶体管与电路市场、DeWEB 工具及链上数据。其挖矿权重考虑制造工本与设计效率，并介绍了与 DeWEB 活跃度、BEM 或 OKB 质押关联的加速机制；协议和市场规则在 X Layer 链上执行。

PROJECT 04活跃

SnapVault

SnapVault 是 X Layer 上的创作者内容分享应用。创作者发布加密图片，粉丝使用 OKB 付费解锁，并可通过私聊和粉丝群建立连接。前端托管于 DeWEB，经 TapeCode 更新，通过 TapeKit 访问。已有可用容器和公钥时，应用使用 TapeSend 交付查看链接，否则采用普通交付。限时查看仅限制站内展示，无法阻止截图或收回已保存内容；交付出现问题时可申请平台退款审核。

TapeDeck

PROJECT 08活跃

TapeFlow

TapeFlow（官网当前品牌为 TapeFlow X）是面向 TapeOut 生态的 X Layer 原生支付入口。官网展示 OKB、X Layer 代币与电路容器支付，以及收款码、红包、担保付款、定时支付、条件锁仓、隐私与跨链支付等入口，并提供商户/API 页面。其电路规则层包括 PaymentGuard、PacketGuard、EscrowState 与 BudgetGuard，通过统一 Policy 接口供支付合约调用。

TapeLaunch

PROJECT 12活跃

TapePool

TapePool 是面向 X Layer 矿工的借贷池：矿工可以用 TapeOut 或 FabX rig 未来挖到的 BEM 作为借款依据，借款由 Rig Agent 持有凭证并用挖矿收益自动归还。协议以 BEM 计价，支持 7 天或 14 天固定费率借款，不依赖预言机，也不因价格波动清算抵押物；出借者存入 BEM 并获得代表池份额的 tpBEM。

TapeSurge

TapeSurge（晶涌协议）是基于 TapeOut PoD 的链上收益分配实验，运行于 BNB Smart Chain。其设计通过汇集 BEM 购入并持有 PoD 矿机：标准局累积产出后逐次抽签分配；月局挖矿 30 天，奖金一半按投入比例分配、一半抽奖，随机数由 Chainlink VRF 提供。目前处于测试网开发阶段，主网参与尚未开放，不承诺固定收益或完成时间。

PROJECT 16活跃

tapeXO

tapeXO 是基于 TapeOut 开发、部署在 X Layer 的 X/Twitter 抽奖工具，支持用 X 登录报名或导入已有推文的转发名单，参与无需连接钱包或签名。名单在开奖前冻结并将哈希上链，commit-reveal 机制结合随机种子与后续区块哈希生成可复算排名。公开名单及结果文件封存进 TapeOut 容器，并通过链上哈希核验；可选关注、转发、持币或持 NFT 等参与条件。链上交易由运营方提交并代付 Gas。
